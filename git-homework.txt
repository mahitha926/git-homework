Git is the version control system that lets you track changes in your code, and Github is the platform that stores git repositories online.
git add <file> puts just one file you choose into the staging area, you use it to add a specific file you changed. git add . puts all the new and changed files in the current folder into the staging area, but it doesn’t include deleted files; it adds everything you changed  inside the current directory. git add -A puts every change in the whole project into the staging area, including new files, changed files, and deleted files.
git push sends the changes you have saved locally to the remote repository, like GitHub, so others can see them. git pull brings the latest changes from the repository down to your local computer and updates your files with them.
git fetch downloads the latest changes from the repository but doesn't update your local files, it just shows you what changed. git pull also downloads the latest changes but then immediately updates and merges them into your local files.
